B站开放平台团队您好：

我们正在开发开源网页转写工具“听写匣”（media-scribe），希望咨询视频音轨读取的官方接入方式。

项目仓库：https://github.com/LYHrmer/media-scribe

期望流程是：用户粘贴 B站视频链接，在 B站官方页面登录并完成所需授权，返回工具后取得指定分P的完整音轨，由浏览器本地开源模型生成文字和标点。用户无需安装客户端或购买模型 API；服务端拟仅临时中转音频，不持久保存媒体或转写结果。

我们已查阅官方 OAuth、网页应用接入、稿件查询和外链播放器文档，尚未确认可返回完整音轨的适用接口。按照“文档中未列出的功能”页面指引，想请教：

1. 是否提供允许上述转写用途的音轨或媒体读取接口？若有，能否提供接口文档、权限名称和申请条件？
2. 用户登录授权后，可处理的范围是其作为作者或联合投稿人的视频，还是也包括获允许的其他公开视频？付费、登录及地区限制将按平台规则处理。
3. 是否接受个人开源项目申请或试点？若必须具备企业主体，请说明资质、审核流程和费用。
4. 是否支持分P选择及完整音轨获取？是否有调用额度、访问域名、临时中转或数据保留方面的要求？
5. 能否提供允许用于验收的样本及沙盒方式？我们会在接入后验证完整取音、实际浏览器转写和文字正确性。

本项目目前处于技术可行性验证阶段，希望先确认准入条件与可用能力，再确定接入安排。如需补充资料，请回复本邮件告知。
