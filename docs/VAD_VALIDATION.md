# Silero VAD：内容保护验证

**VAD 仅将整片标为可恢复的“暂未检测到明确人声”候选，保留原文件及“仍然尝试识别”入口；它不是已证实无歌声，也不代表转写内容已经正确。**

此测试采用官方 Silero 2,327,524 字节 ONNX 模型，MIT 许可，固定 revision `1e261b036686cd0017d500ee96acd1c4ba572a9d`。模型与源 wrapper / 许可的来源、SHA-256 见 `benchmarks/vad-provenance.json`；不包含用户媒体。模型只能从当前网页读取，GET 与缓存都校验固定字节数和 SHA，HTML / 403 / 损坏内容不缓存。下载有 60 秒超时，失败继续原 ASR。

## 固定策略

- 16 kHz，512 样本即 32 ms 一帧，64 样本上下文，`state[2,1,128]` 每文件重置；跨传输块保留同一 state、context 和连续弱峰计数。
- 任一帧 p ≥ 0.5，或连续两帧 p ≥ 0.05（64 ms）即保留声音。弱概率阈值没有提升，单帧低概率尖峰不作为可靠人声证据。
- 只有整片至少 2 秒、全部概率有效、全部帧已检查、没有以上证据才给出候选。短于 2 秒、用户强制识别、未知 / 歌词旁路和检测故障都保留声音。
- 标准 0.5 VAD 区间只供诊断。它对用户歌声返回 0 段，不能用于切音频或决定没有歌词。本功能不切片。

## 发现并保留的反例

先前只要一帧 p ≥ 0.05 即保留的规则，放行了 65 秒无语音噪声。它由原 5 秒 seeded uniform 噪声重复 13 遍生成，非新增真实录音；2032 帧中只有第 165 帧（5.280 秒）超过 0.05，全片最大 p 为 0.0503186882。原失败保留在 JSON，没有通过抬高概率阈值隐藏。

固定两帧时间一致性消除了这个孤立弱峰的影响，完整检查 2032 帧后判为候选。对用户歌声，虽然没有 p ≥ 0.5 的强峰，弱峰最长持续 14 帧、0.448 秒，因此仍保留。单强峰、单弱峰、相邻弱峰、跨块弱峰均有专项测试。风险仍是长文件中的极短、低置信人声可能被当成候选；原文件保留及强制重试必须存在。

## 生产流式 Worker

主线程每次只复制 32 秒 PCM（约 2 MB），仅转移该副本；收到确认才发送下一块，不转移或脱离原 PCM buffer。任一强峰 / 连续弱峰即可提前保留，记录 `analysisComplete:false`、`observedMax`，不把已观察峰值伪装为全片峰值（`maxProbability:null`）。只有完整候选才保存完整最大值。检测每 4 帧让出事件循环，AbortSignal 终止 Worker；错误和反序列化失败软降级继续 ASR。

实际构建后的 Vite Worker `vad.worker-C9h8-FgH.js` 已在浏览器形态 VM 中运行真实 ONNX WASM；本机模型 GET 和 Cache API 被模拟。这不是源 engine 单独运行，也不是华为 / Chrome UI 或原生媒体解码验收。worker / source / WASM / model SHA 全部在 JSON。

| 实际 built 用例 | 块数 | 候选 | 完整扫描 | 检查帧数 |
|---|---:|---|---|---:|
| noise | 1 | 是 | 是 | 157 |
| user-lyrics | 1 | 否 | 否 | 7 |
| silence-33s-plus-clean-derived | 2 | 否 | 否 | 1034 |

第二个 Worker 校验并复用缓存，没有新增模型 GET。33 秒静音后接清晰讲话的 38.592 秒派生样本跨两个块仍保留，证明不会因前 32 秒无声就提前判空；65 秒派生噪声跨三个块完整检查。

另验证 1、16、128、511、512、513、1600、7999、8000、16000 个样本的末帧边界；极短切片声学信息不足，全部因短片保护保留。不声称这些切片已能可靠分类。

## 复现

```sh
node scripts/prepare-vad.mjs
npm run build
node --experimental-vm-modules scripts/verify-vad-wasm.mjs dist YOUR_LOCAL_CASE_MANIFEST YOUR_LOCAL_OUTPUT_JSON
node --test tests/vad*.test.mjs
```

本机 case manifest 使用前面套件准备的 `noise`、`user-lyrics`、`zh-clean` PCM，用户歌词视频需本机提供；不提交视频或音轨。校验脚本自行生成 33 秒静音+讲话和 65 秒重复噪声派生控制。更多实际录音、耳语、轻声、长歌声、音乐和噪声仍需独立验证；模型概率不是通用声学保证。
