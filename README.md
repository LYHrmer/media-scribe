# 听写匣 · 浏览器本地版

拖入视频或音频，点击开始，把识别结果复制或导出为 TXT、SRT、VTT、JSON。

无需安装软件、账号、API Key 或按次数付费。网页使用多语言 Whisper 模型，由用户浏览器执行识别；音视频不会上传到我们的服务器或模型服务。首次使用会从本网页所在站点下载模型和浏览器运行库，使用者无需连接 Hugging Face。浏览器可缓存这些文件；缓存可能被清理，或因空间/隐私模式不可用，因此不能保证永久离线。

默认选择高精度模型和中文。提供快速与高精度两档；高精度使用 Whisper Small q4f16，首次模型下载约 190 MB，需要更多时间与内存。完成后可直接点击「不满意，重新转写」；未手动改变精度时，会从快速升级到高精度。失败或停止时保留原稿，成功后可恢复上一版。结果需要校对，不含说话人区分或翻译功能。

## 当前范围

- 桌面版较新的 Chrome / Edge 优先；其他浏览器需实际验证。
- 手机主入口使用通用文件选择，另有独立录音、视频入口，以及可见的原生单文件入口。若应用内置浏览器提示「暂无可用打开方式」，可直接使用「手机推荐」单文件入口，或展开提示复制网址到系统浏览器。网页无法修复宿主应用缺失的原生文件选择能力；华为 / 鸿蒙真机仍需验证。
- WAV、MP3 和部分 M4A/MP4 的读取取决于浏览器解码器。不是所有视频编码都能直接识别。
- 单文件限制 300 MB、音轨 30 分钟。解码会读取完整文件，较长的文件可能耗费较多内存，建议先用短录音。
- 停止任务会终止识别 Worker；已完成文件的结果保留。
- TXT 使用编辑后的正文；字幕及 JSON 保留原始片段及时间。
- 模型分片逐个下载并校验 SHA-256，下载中断或文件不完整时会给出明确提示。没有伪造示例转写。
- 保守处理连续近静音，保留声音前后上下文，并把分段字幕映射回原始时间轴。该算法不能区分歌声、伴奏或环境噪声。
- 中文、英语均明确指定语言；当前库没有真正的自动语言检测，因此不提供误导性的「自动判断」。
- 歌声、强伴奏和现场回声可能导致漏字或幻觉。连续重复或长声音段只识别少量文字时会显示提示，不会自动删除正文或编造置信度。

## 开发和自托管

普通使用者只需打开网页。以下操作仅供部署者：

```bash
npm install --onnxruntime-node-install-cuda=skip
npm test
npm run build
npm run dev
```

构建时从 Hugging Face 获取两种模型并缓存到 `.cache/models/`，也可用 `MODELS_CACHE_DIR` 指定已有缓存。运行库复制到 `vendor/ort/`，模型配置与不超过 16 MiB 的分片写入 `models-v2/`。部署完整 `dist/` 为 HTTPS 静态网站即可，无需额外的 API 服务。首次开发预览前请先构建，以准备模型与运行库。构建不需要 CUDA；浏览器运行也不使用 Node 的 GPU 包。

## 验证

89 项自动检查覆盖音频预处理、近静音分段、字幕时间偏移、任务取消与重试、旧稿恢复、Worker 配置，以及模型分片下载与完整性校验；新增站点资源 401/403 提示、运行文件错误页缓存隔离检查；还验证手机文件入口的筛选、文件校验、取消保留原稿、重选、运行时禁用与浏览器链接复制。真实 11 秒英文录音通过 Tiny/Base 的实际 ONNX WASM 转写，5.592 秒中文讲话通过 Small q4f16 的实际 WASM 转写；测试执行生产 Worker、模型加载器和构建后的浏览器推理库，未模拟识别结果。该检查在 Node VM 中模拟 GET 与 Cache API，并将 WASM helper 映射到本地文件，不能代替 Chrome 中的文件解码与完整点击流程。目标浏览器交互验证仍需补充。

GitHub Pages 的备用托管配置和入口拦截说明见 [DEPLOYMENT.md](docs/DEPLOYMENT.md)。备用网址只有在仓库成功发布后才可使用。

## 参考与拆解

借鉴 [Whisper Web](https://github.com/xenova/whisper-web) 的本地解码、Web Worker、30 秒分块与字幕设计。明确使用多语言模型及中文识别，没有沿用英文专用 `.en` 模型。

按用户要求安装并执行了 [REA](https://github.com/morluto/rea) 6.4.0，对 OpenWhispr 的源码样本做静态分析尝试。完整应用分析受环境进程检查限制；随后通过受支持的参考源码导入，成功解析 OpenWhispr 与 Vosk 浏览器版的两组源码切片，共 20 个文件、52 条导入/引用关系。具体算法结论与公开源码交叉核对，未完成整款应用或商业程序的二进制反编译。

REA 与源码分析的实际收获：避免 Electron 与本地 Whisper 服务带来的安装负担；让 Worker 承担识别，保持界面可操作；展示首次模型下载进度；只把模型资产发起网络下载，文件和结果在本地处理。

代码许可见 LICENSE。Whisper、Transformers.js、ONNX Runtime 等依赖各自保留原许可，模型不包含在源码包中。

本轮拆解、实际模型对比与明确限制见 [ASR_ANALYSIS.md](docs/ASR_ANALYSIS.md)。
